## G2Stubs
---
#### About
This contains:

(1) stubbed out versions of certain quasiquoter functions from G2:

https://github.com/BillHallahan/G2

This allows G2 to compile against the stubbed out functions, rather than the whole (intractable) real code.

(2) SMT translation of functions over strings/lists, which G2 can load and use to analyze these functions behavior via an SMT solver.
